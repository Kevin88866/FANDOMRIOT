# 饭圈风云 · FANDOM RIOT

一个首尔电竞饭圈 3D 模拟游戏（自用，不发布）。你是一个粉丝博主：开 LED 卡车、送花圈、拉横幅、砸臭鸡蛋、喷涂鸦、组织集会、放烟花、搞无人机灯光秀，用手机拍下来发到社交平台换曝光、粉丝和钱。你的行动会影响选手心态 → 比赛结果 → 舆论热度。

## 怎么玩
- **Windows**：解压 `FandomRiot-win32-x64.zip`（不在仓库里，可用 `npm install && npm run pack:win` 自己打包到 dist/），双击 `FandomRiot.exe`。F11 全屏。
- **开发 / 其他系统**：装好 Node.js 后 `npm install`，再 `npm start`。也可以 `npm run serve`，然后用浏览器打开 http://localhost:8123 。

操作：WASD 移动/开车 · Shift 跑 · 空格 刹车 · F 上下车 · E 互动 · C 手机拍照（左键拍、滚轮变焦）· Tab 背包 · M 大地图 · H 收起目标面板 · Esc 菜单
摆放模式：鼠标移动 · 左键放下 · Q / E 或滚轮旋转 · 右键取消

## 每周流程
1. **比赛日**（直播风格）：赛果、MVP 和背锅位、热搜榜、选手动态，以及"你的行动 → 心态 → 本场表现"因果链。
2. **私信**：有时会收到俱乐部、选手本人、对手粉头等的私信，二选一 / 三选一，影响后续。
3. **行动日**（游戏内 18:00–24:00）：
   - 用品店买道具 → 到目标选手所在的总部（其他战队在 LCK 竞技场）使用。花圈、花篮、横幅、集会进入俯视摆放模式，"排面"影响照片质量；堵门曝光更高，但保安会来清理。
   - 卡车类道具去车行提车，自己开到门口展示，或者雇司机沿大路巡游。
   - 每晚 3–4 个限时机会事件：选手下班（拍到他看见你的道具 = 最值钱的名场面）、电视台采访、对手粉头卡车抢镜对决、街头主播路过（可以接受直播采访）。
   - 手机拍照：黄框标出主体，"画面质量"条实时显示；LED 卡车要等标语滚到屏幕中间。
4. **发帖**（社交 App 风格）：每天最多 3 条，选平台和语气；结果有点赞/转发/评论滚动和网友评论。
5. **周结算**：商单任务、商单收入、房租、争议度后果、粉丝团变化、技能升级。

曝光 = 道具冲击力 × 照片质量 × 话题热度 × 情绪匹配 × 新鲜度 × 平台偏好 × 名场面 × 粉丝团 × 运气（约 4% 爆款，10% 石沉大海）。

## 修改名字和数值
- 战队名、选手名、招牌文字、默认标语、道具价格和平衡参数：**`src/content/data.js`**
- 私信剧情、每周商单、成就：**`src/content/story.js`**

改完重新打开游戏就生效（打包版需要重新打包：`npm run pack:win`）。数值平衡可以用 `npm run simulate` 跑机器人模拟检查。

开发用的预览页：`/tools/dev/actors.html`（人物 × 动画）、`/tools/dev/vehicles.html`（所有车辆）。
