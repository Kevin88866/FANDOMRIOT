# 饭圈风云 · FANDOM RIOT

一个首尔电竞饭圈 3D 模拟游戏（自用，不发布）。你是一个粉丝博主：开 LED 卡车、送花圈、拉横幅、组织集会、放烟花、搞无人机灯光秀，用手机拍下来发到社交平台换曝光、粉丝和钱。你的行动会影响选手心态 → 比赛结果 → 舆论热度。

## 怎么玩
- **Windows**：在 Releases 下载 `FandomRiot-win32-x64.zip`，解压后双击 `FandomRiot.exe`。F11 全屏。
- **开发 / 其他系统**：装好 Node.js 后 `npm install`，再 `npm start`。也可以 `npm run serve`，然后用浏览器打开 http://localhost:8123 。

操作：WASD 移动/开车 · Shift 跑 · 空格 刹车 · F 上下车 · E 互动 · C 手机拍照（左键拍、滚轮变焦）· Tab 背包 · M 大地图 · Esc 菜单

## 每周流程
1. **比赛日**：看赛果、MVP 和背锅位、热搜榜、本周新闻。
2. **行动日**（游戏内 18:00–24:00，约 6 分钟）：去用品店买道具 → 到目标选手所在的总部（其他战队在 LCK 竞技场）使用 → 拍照。卡车类道具去车行提车，可以自己开，也可以雇司机沿大路巡游，你在路边拍。
3. **发帖**：每天最多发 3 条，选平台和语气。
4. **周结算**：商单收入、房租、争议度后果、技能升级。

曝光 = 道具冲击力 × 照片质量 × 话题热度 × 情绪匹配 × 新鲜度 × 平台偏好 × 运气（约 4% 爆款，10% 石沉大海）。

## 修改名字和数值
所有战队名、选手名、招牌文字、默认标语、道具价格和平衡参数都在 **`src/content/data.js`**，改完重新打开游戏就生效（打包版需要重新打包：`npm run pack:win`）。

数值平衡可以用 `npm run simulate` 跑机器人模拟检查。

## 素材
- 人物模型（Michelle / Soldier / Xbot）、HDR 天空：来自 three.js 官方示例仓库（MIT）。
- 其余模型、贴图、音效全部由代码生成。
